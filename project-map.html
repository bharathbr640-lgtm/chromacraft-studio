ChromaCraft Studio

A professional-grade color architecture and accessibility engine for high-fidelity design systems.

High-Level Architecture

Color Picker

Interactive HSL wheel and precision channels for color selection.

ColorCore Engine

Central Brain: State management & mathematical color conversions.

Harmony Engine

Generates geometric palettes (Triadic, Analogous, etc.).

Gradient Studio

Multi-stop linear, radial, and conic gradient creator.

A11y Suite

WCAG 2.1 Contrast engine and vision simulation.

Token Export

Generates CSS, SCSS, Tailwind, and binary .ASE files.
